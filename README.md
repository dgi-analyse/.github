# DGI Analyse

DGI Analyse utvikler løsninger for databehandling, rapportering og automatisering.

Målet er å redusere manuelt arbeid, forbedre datakvalitet og gjøre arbeidsprosesser enklere og mer robuste.

## Fagområder

* Databehandling og datavask
* Rapportering og automatisering
* Python-utvikling
* SQL og analyse
* Datakvalitet og validering
* API-er og systemintegrasjoner
* Interne webapplikasjoner

## Teknologi

DGI Analyse benytter blant annet:

* Python
* SQL
* Docker
* Streamlit
* DuckDB
* Polars

## Prinsipper

Løsninger skal være:

* Enkle å bruke
* Enkle å drifte
* Enkle å videreutvikle
* Tilpasset faktiske behov
